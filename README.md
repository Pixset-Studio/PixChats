# ⚡ PixChats — Кроссплатформенный защищённый мессенджер (Web, Windows `.exe`, Android `.apk`)

**PixChats** — современный быстрый мессенджер от **Pixset Studio** с фирменным **жёлто-чёрным дизайном (`#FFD400` / `#080809`)**, сквозным шифрованием (E2EE AES-256-GCM), личными аудио- и видеозвонками, групповыми голосовыми чатами, прямыми эфирами в каналах с демонстрацией экрана, управлением активными устройствами и полностью автоматическим самообновлением на ПК и Android.

---

## ✨ Ключевые возможности PixChats

### 💬 1. Общение, чаты, группы и каналы
- **Личные чаты, публичные и приватные группы, каналы**:
  - Поддержка **тем (топиков)** внутри групп и каналов, а также **комментариев под постами** в каналах.
  - **«Избранное» (Saved Messages)** — личное облачное хранилище заметок, пересланных сообщений и медиафайлов.
  - **Папки чатов и Архив**: быстрые фильтры (`Все`, `Личные`, `Группы`, `Каналы`, `Архив`) + создание собственных кастомных папок и закрепление важных чатов.
- **Полное бесследное удаление сообщений**:
  - **«Удалить у меня»** — мгновенно убирает сообщение только на вашем аккаунте.
  - **«Удалить у всех»** — полностью стирает сообщение у всех собеседников в реальном времени без каких-либо заглушек вроде *«Сообщение удалено»*.
- **Богатые возможности сообщений**:
  - Форматирование текста (жирный, курсив, моноширинный код, спойлеры `||скрытый текст||`), встроенный переводчик RU ⇄ EN.
  - Голосовые сообщения с выбором скорости воспроизведения (`1x`, `1.5x`, `2x`) и **видеосообщения в кружочках (Video Notes)**.
  - Отправка фото, видео, аудио, документов и **секретных медиа под спойлером / с одноразовым просмотром**.
  - **Исчезающие сообщения** по таймеру (самоуничтожение без следов после истечения времени).
  - **Опросы и голосования** прямо в чатах, быстрые реакции с анимацией частиц, кастомные стикерпаки с дедупликацией по ID.
  - Мгновенные статусы прочтения (`✓` доставлено / `✓✓` прочитано) и живые индикаторы активности (*«печатает…»*, *«записывает голосовое…»*, *«записывает кружочек…»*).

### 📞 2. Звонки, групповые голосовые комнаты и прямые эфиры
- **Личные 1-на-1 аудио- и видеозвонки**:
  - Гибридный движок **WebRTC P2P + Realtime Low-Latency PCM Audio Relay** — гарантирует чистый звук даже за строгим NAT/симметричным файрволом без необходимости внешнего TURN-сервера.
  - Переключение камеры, демонстрация экрана, индикатор качества связи и защита от случайного сброса.
- **Групповые голосовые чаты (Voice Chats)**:
  - Поддержка до нескольких десятков участников одновременно с индикацией говорящих спикеров, включением камеры и шерингом экрана.
- **Прямые эфиры в каналах (Live Streams)**:
  - Ведущий канала может запустить прямой эфир с голосом, веб-камерой или демонстрацией экрана.
  - Зрители могут **«✋ Поднять руку»**, а ведущий может дать слово любому подписчику в прямом эфире.

### 🔐 3. Безопасность, E2EE и управление устройствами
- **Сквозное шифрование (End-to-End Encryption)**:
  - Все сообщения шифруются алгоритмом **AES-256-GCM (Web Crypto API)** с поддержкой сверки криптографического отпечатка безопасности (Safety Fingerprint) и установки дополнительного пароля шифрования на чат.
- **Вкладка «💻 Устройства» в настройках (`/settings`)**:
  - Отображает все активные устройства и сеансы вашего аккаунта (`Windows Desktop .exe`, `Android .apk`, `Web-браузер`) с информацией об ОС, версии приложения, часовом поясе и времени последней активности.
  - Позволяет **завершить любой отдельный сеанс** или нажать **«🛑 Завершить все другие сеансы»** — отключённое устройство мгновенно разлогинивается в реальном времени через Supabase Realtime.
- **PIN-код и скрытие секретных чатов (AppLock)**:
  - Защита входа в приложение PIN-кодом, автоблокировка при неактивности и возможность скрыть приватные чаты из общего списка.
- **Гибкие способы входа**:
  - Вход по **паролю** или **одноразовому коду с почты (OTP)**, OAuth через **Google, VK ID, Яндекс ID**, а также единый вход через **Pixset Studio ID**.

### 🔄 4. Полностью автоматическое самообновление (`.exe` и `.apk`)
- **Единая версионность и список «Что нового»**:
  - GitHub Actions автоматически собирает `PixChats-Setup.exe` и `PixChats.apk` с единым номером версии (`v0.2.<commit_count>`) и публикует релиз с подробным чейнджлогом **«✨ Что нового»**.
  - Если у пользователя уже установлена актуальная версия, приложение не предлагает скачивать её повторно, а при ручной проверке сообщает: *«✅ У вас установлена последняя версия PixChats»*.
- **Автоматическая фоновая самоустановка без ручных действий**:
  - **На ПК (Windows `.exe`)**: приложение само скачивает инсталлятор в фоновом режиме с прогресс-баром, запускает тихую установку (`NSIS /S`) и автоматически перезапускает обновлённый PixChats.
  - **На телефоне (Android `.apk`)**: приложение само скачивает новый `.apk` и запускает пакетную установку через `PackageInstaller.Session` (`USER_ACTION_NOT_REQUIRED` на Android 12+ для обновлений от того же установщика). Все `.apk` подписываются **единым постоянным ключом** (`pixchats-release.keystore`) с авто-инкрементом `versionCode`, поэтому обновление всегда ставится **поверх текущей версии без удаления приложения**.

### 🛡️ 5. Админ-панель, модерация и Центр помощи (FAQ)
- **Панель администратора и разработчика (`/admin`)**:
  - Статистика платформы, управление ролями (`developer`, `admin`, `moderator`, `partner`, `vip`, `user`), выдача фирменной галочки верификации и бейджа сотрудника Pixset Studio, заморозка (`❄️`) и временный/постоянный бан аккаунтов.
- **Встроенный Центр помощи (`/faq`)**:
  - Подробная интерактивная база знаний по всем функциям мессенджера с поиском по вопросам и категориям.

## 🚀 Быстрый старт и локальная разработка

### 1. Настройка базы данных Supabase
1. Создайте проект на [supabase.com](https://supabase.com).
2. В разделе **SQL Editor** последовательно примените миграции из папки `supabase/migrations/` (`0001_init.sql` … `0027_chat_members_delete_policy.sql`).
3. Скопируйте `apps/web/.env.example` в `apps/web/.env.local` и укажите `NEXT_PUBLIC_SUPABASE_URL` и `NEXT_PUBLIC_SUPABASE_ANON_KEY`.

### 2. Запуск в режиме разработки
```bash
npm install
npm run dev
```
Приложение откроется на `http://localhost:3000`.

### 3. Выдача роли разработчика (`@pixset`)
В Supabase SQL Editor выполните:
```sql
update profiles set role = 'developer', is_verified = true where username = 'pixset';
```

## 📦 Сборка и авторелизы Windows (`.exe`) и Android (`.apk`)

Обе нативные сборки выполняются автоматически в **GitHub Actions** при каждом пуше в ветку `main` (а также доступны для ручного запуска через **Actions → Run workflow**):

- **Windows Desktop (`.exe`)** — `.github/workflows/build-desktop.yml`:
  - Собирает статический бандл Next.js, упаковывает его в Electron (`apps/desktop`) с локальным HTTP-сервером, системным треем и модулем тихого автообновления `installUpdate`.
- **Android Mobile (`.apk`)** — `.github/workflows/build-mobile.yml`:
  - Генерирует Capacitor Android-проект (`apps/mobile`), применяет единый постоянный ключ подписи `pixchats-release.keystore` (`configure-android-native.js`), подключает нативный мост `PixChatsAndroid` (`PackageInstaller.Session`, системные пуш-уведомления и аудио-фокус для звонков) и собирает готовый `PixChats.apk`.
- **Публикация релиза**:
  - Старый релиз автоматически очищается, а новый публикуется под тегом конкретной версии `v0.2.<commit_count>` и содержит одновременно и `PixChats-Setup.exe`, и `PixChats.apk`, а также блок **«✨ Что нового»**.
